# Plotify — Codebase

This repository contains the application code for Plotify, 
a personal TV episode tracker with calendar integration 
across streaming platforms.

**Built with:** React · TypeScript · Vite · Lovable  
**Live Product:** [getplotify.vercel.app](https://getplotify.vercel.app)  
**Product Documentation:** [github.com/pav-sabanathan/getplotify](https://github.com/pav-sabanathan/getplotify)
